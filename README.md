# Gesture Glove
ML Gesture recognition using edge impulse & RPI pico.
Detects gestures and performs shortcuts accordingly using a python script.
###### Fun fact: EdgeImpulse mentioned GestureGlove on [linkedin](https://www.linkedin.com/feed/update/urn:li:activity:6909140611157606400/) on #PiDay

# Layout
    src/                firmware sources
    vendor/             vendored edge impulse sdk
    model-parameters/   generated by edge impulse, overwritten on re-export
    tflite-model/       generated by edge impulse, overwritten on re-export
    host/               host side python project (its own pyproject.toml)
      src/gesture_glove/  config loading, serial reading, action dispatch
      config.json       gesture -> shortcut profiles

# Requirements
* Cmake
* Pico SDK (`PICO_SDK_PATH` must be set)
* [uv](https://docs.astral.sh/uv/) for the python receiver

# Steps
### 1. connect your pico while holding the bootsel button
### 2. run the following:
    export PICO_SDK_PATH=~/pico-sdk
    export PICO_TOOLCHAIN_PATH=/opt/homebrew/Cellar/arm-none-eabi-gcc@8/8.5.0_2
    mkdir build && cd build && cmake .. -DPICO_BOARD=pico && make -j
### 3. copy build/gGlove.uf2 to RPI-RP2 when its connected

> On macOS, Homebrew's core `arm-none-eabi-gcc` ships without newlib and fails to link
> (`cannot find -lc`). The older `osx-cross/arm/arm-none-eabi-gcc@8` includes it, hence
> the explicit `PICO_TOOLCHAIN_PATH` above.

# Connections
* PICO 3v3  -> MPU6050 VCC
* PICO GND  -> MPU6050 GND
* PICO GP4  -> MPU6050 SDA
* PICO GP5  -> MPU6050 SCL
* PICO GP0  -> HC-05 RX
* PICO GP1  -> HC-05 TX
* PICO VBUS -> HC-05 VCC
* PICO GND  -> HC-05 GND

# Host receiver
Receives gesture labels from the Pico and performs the shortcuts saved in **host/config.json**.  
If no profile is passed in the command arguments, the default profile is used.  
Dependencies are declared in **host/pyproject.toml**; `uv run` installs them on first use.
##### To run (from host/) :     
    uv run glove-receiver <COM_PORT> [PROFILE]

e.g. ``` uv run glove-receiver COM3 Music ```  
Or from the repo root: ``` uv run --directory host glove-receiver COM3 Music ```

Type check with ``` uvx pyrefly check ``` from **host/**.  
Available key names for **config.json** are listed at the bottom of `host/src/gesture_glove/actions.py`. Combine them with `+`.

> NOTE:
>
> * THIS BRANCH USES **BLUETOOTH** NOT USB
> * THIS PYTHON SCRIPT IS INTENDED FOR **WINDOWS**, IT HAS NOT BEEN TESTED WITH OTHER PLATFORMS.
